## 纯前端架构

```
index.html
 ├─ pack.js      最小 ZIP writer（store 模式 + CRC32）、洋红键合成、圆形贴纸
 ├─ runtime.js   win_pet.ps1 / start.bat / README.txt 模板（字符串常量）
 ├─ export.js    buildPackage({cfg, spriteNames, customCanvas}) → Blob
 └─ app.js       状态、预览、拖动、上传、分享链接、导出按钮
```

设计要点：

- **没有后端**：所有照片处理、抠图、ZIP 组装都在浏览器里完成，关闭页面即清空。
- 不用 CDN、不用 JSZip：`buildZip()` 自己写 local file header / central directory / EOCD，文件名带 UTF-8 flag。
- 资源用 `<script>` 同步引入，避免静态托管对 `.ps1` 等未知扩展的 MIME 问题。
- 定制台抽屉在 `?s=` 参数存在时自动展开，便于小程序分享链接落地。

## 交互清单

- Hero 预览窗里的宠物可拖动、点击触发台词气泡。
- chips / gallery 卡片 / 动作按钮 / 三步区的姿势图都会同步预览。
- 上传照片：`sticker()` 做中心裁切 + 径向渐变羽化的圆形贴纸，不上传服务器。
- 台词：加入文案表，导出后由桌宠随机说；点击 chip 可删除。
- 分享链接：把配置编码进 URL query，朋友打开自动还原（见 `URL定制参数.md`）。
- 导出：`export.js` 载入该形象的动作 PNG，`magentaKey()` 把 alpha 二值化到洋红底，再写进 ZIP。

## 素材

`assets/pet/` 为 7 种形象的动作精灵图（原图自带透明通道，直接复用）；`assets/*.webp` 为展示用海报；`assets/*.svg` 为品牌与平台图标。

> 这些是原站演示素材。**商用前替换成自有图片与品牌名称**，避免侵权。

## 常见坑

- 半透明毛发边缘直接合成到洋红会产生粉色晕，必须把 `alpha < 128` 的像素**整体替换为纯洋红**。
- 中文文件名在部分解压工具里会乱码，ZIP 内保持 ASCII，只有下载文件名可以中文。
- `win_pet.ps1` 与 `scripts/win_pet.ps1` 内容必须一致，否则 CLI 包与网页包行为不同。
