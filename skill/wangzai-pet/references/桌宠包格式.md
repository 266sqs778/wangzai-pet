# 桌宠包格式与运行时

## 两种包

| | 轻量 BAT 包 | EXE 完整版 |
|---|---|---|
| 体积 | 几十 KB ~ 300 KB | 约 17 MB |
| 入口 | `start.bat` → `win_pet.ps1` | `wangzai-pet.exe` |
| 依赖 | Windows 10/11 自带 PowerShell 5.1 + .NET Framework | 无（PyInstaller 打包了 Python 与 Pillow） |
| 功能 | 拖动、走动、气泡、动作切换、右键菜单、置顶 | 额外有滚轮缩放、设置面板、更多动作、配置热更新 |
| 素材 | 洋红键不透明 PNG | 透明通道 PNG |
| 适合 | 分享给朋友、免费分发 | 深度用户、需要完整控制台 |

## 轻量包 ZIP 布局

```
pet-config.json          UTF-8 JSON，唯一配置来源
win_pet.ps1              PowerShell 运行时（必须 UTF-8 BOM）
start.bat                ASCII，双击入口
README.txt               中文说明（带 BOM）
assets/pet/*.png         动作图，纯洋红 #FF00FF 背景的不透明 PNG
```

`start.bat` 内容：

```bat
@echo off
title Wangzai Desktop Pet
cd /d "%~dp0"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "%~dp0win_pet.ps1"
```

`-ExecutionPolicy Bypass` 只影响本次调用，不修改系统策略。

## 洋红透明键

WinForms 的 `Form.TransparencyKey` 只抠**精确等于** `#FF00FF` 的像素。因此导出图片必须：

1. 读取带 alpha 的精灵图；
2. `alpha < 128` → 输出 `(255, 0, 255)`；`alpha >= 128` → 输出原 RGB；
3. 输出不带 alpha 通道的 PNG。

网页实现在 `pack.js` 的 `magentaKey()`，CLI 实现在 `scripts/make_bat_pack.py` 的 `magenta_key()`，两者行为必须一致。

## pet-config.json 字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `name` | string | 名字，出现在启动气泡与标题 |
| `species` | string | 形象 key；自定义照片用 `my` |
| `size` | int | 窗口边长，运行时夹到 80–520 |
| `speed` | int | 每 60ms 移动像素，运行时夹到 1–12 |
| `auto` | bool | 是否自动随机切换动作 |
| `topmost` | bool | 是否置顶 |
| `lines` | string[] | 随机台词，双击与定时触发 |
| `note` | string | 生成来源标记（可选） |
| `opacity` / `visible` / `action` / `seq` / `command` | — | 仅 EXE / Python 版使用 |

EXE 版额外读取 `assets/pet/*_left.png` 作为朝左走的镜像帧。

## 运行时能力（win_pet.ps1）

- 无边框、`ShowInTaskbar=false`、`TopMost`、洋红透明键；
- 初始位置：主屏工作区右下角；
- 左键拖动（form 与 picturebox 都绑定，避免图片区域吃掉事件）；
- 双击随机台词气泡；
- 右键菜单：逐个动作、散步/暂停、叫一声、置顶开关、藏 10 秒、退出；
- `Timer` 每 60ms：横向走动碰边界折返、每 90 tick 换动作、每 240 tick 随机说话；
- 事件脚本块统一使用 `$script:` 作用域，避免闭包丢变量；
- 动态菜单项用 `.GetNewClosure()` 捕获循环变量。

## 排查

| 现象 | 原因 |
|---|---|
| 出现洋红方块 | 图片没做二值化，或透明键颜色不一致 |
| 中文气泡乱码 | ps1 缺 UTF-8 BOM |
| 双击无反应 | 直接在压缩软件里运行了，没有解压整个包 |
| 宠物不动 | `auto` / `speed` 配置，或被拖动状态卡住 |
| 安全软件拦截 | PowerShell 脚本误报，添加信任或改用 EXE 版 |
| 窗口不显示 | 检查是否以交互式桌面会话运行；服务/计划任务会话无 GUI |
