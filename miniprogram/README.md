# 望崽宠乐园 · 微信小程序

一个**静态、无需云开发、无需后端**的小程序：手机里定制形象与台词，生成一条定制链接，发到电脑浏览器打开，网页在本机打包出免安装的桌宠包（BAT / EXE）。

## 目录结构

```
config.js                 站点地址、分享码、形象列表、配置读写、链接拼装
app.js / app.json / app.wxss
pages/index               首页与三个入口
pages/customize           选形象 / 起名字 / 大小速度 / 台词
pages/preview             定制摘要、复制链接、发到电脑的四步说明
pages/guide               公众号注册、关联、菜单挂载、资质与多小程序规则
images/                   本地宠物图（不依赖外部域名）
project.config.json       导入开发者工具用的工程配置
```

## 导入并运行

1. 打开**微信开发者工具** → 导入项目 → 目录选本文件夹。
2. `project.config.json` 里的 `appid` 目前是 `touristappid`（测试号）。
   拿到自己的 AppID 后替换它；也可以直接用「测试号」在模拟器里预览。
3. 若部署了新网站，只改 `config.js` 顶部的 `SITE_BASE` 与 `SHARE_CODE`。
4. 点击编译，即可在模拟器里走完：定制 → 生成链接 → 复制 → 查看挂载指南。
5. 真机预览：开发者工具点「预览」，用微信扫码。

## 发布到自己公众号

1. 在公众号后台「小程序管理 → 添加 → 快速注册并认证小程序」创建小程序（复用公众号资质，免 300 元认证费）。
2. 拿到 AppID，替换 `project.config.json`。
3. 完成 **ICP 备案**（小程序上架前必须）、设置服务类目。
4. 开发者工具「上传」→ 小程序后台「版本管理」提交审核 → 发布。
5. 公众号后台把已发布的小程序挂到：
   - 自定义菜单（跳转小程序，需填备用网页）
   - 图文消息中的小程序卡片
   - 自动回复 / 客服消息卡片
   - 资料页「相关小程序」模块

详细规则（数量上限、主体资质、关联限制、web-view 限制）见小程序内「挂到我的公众号」页，以及项目根目录 `docs/微信公众号与小程序指南.md`。

## 为什么不用 web-view

`web-view` 只对企业主体小程序开放，还要求配置业务域名并上传校验文件。本项目为了让**个人主体也能用**，采用「小程序生成链接 → 用户在电脑浏览器打开」的方式，绕开域名与主体限制，同时不产生任何服务器成本。

## 数据与隐私

- 配置只存在手机本地 `wx.setStorageSync('petConfig')`。
- 小程序不发起任何网络请求，不需要配置服务器域名。
- 照片处理完全在电脑浏览器内完成，不上传。

## 校验

运行项目根目录的 `python tools/validate_all.py` 可检查 JSON 严格性、页面文件完整性、JS 语法与 WXML 常见错误。
