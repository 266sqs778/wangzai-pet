选一张正面、光线好的照片，会自动裁成柔和的圆形宠物贴纸。照片只在本机浏览器里处理。

带上它回家

生成一个 免安装的 Windows 桌宠包：BAT + 素材 + 配置，解压后双击 start.bat 即可上桌。不联网、不装 Python、可自由分享。

⬇ 或下载 EXE 完整版（17 MB）

轻量包用 BAT 启动、几十 KB，方便发给朋友；EXE 版自带完整动作与右键菜单，直接双击可执行文件。

「我的分享码」会把当前定制生成专属二维码，朋友扫码直接看到这只宠物。

全部计算在浏览器本地完成，关闭页面即清空。导出的包里含 pet-config.json，可以随时用记事本改名字、大小、台词。
