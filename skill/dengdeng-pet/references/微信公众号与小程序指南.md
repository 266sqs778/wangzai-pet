# 微信公众号 → 小程序：注册、资质、挂载完全说明

> 查证时间：2026-11-11。微信规则会调整，最终以你后台页面上的实时提示与官方公告为准。
> 本文回答三个问题：**怎么用公众号注册小程序**、**怎么挂到公众号里**、**我有多个小程序时资质是怎么算的**。

---

## 0. 先建立一个心智模型

| 概念 | 是什么 | 关键点 |
|---|---|---|
| 公众号 | 一个独立账号（订阅号 / 服务号） | 有主体（个人 / 企业 / 个体户…）、有认证状态 |
| 小程序 | **另一个独立账号** | 有自己的 AppID、独立邮箱、独立后台、独立开发者 |
| 主体资质 | 账号背后的「谁」（身份证 / 营业执照） | **所有数量上限都算在主体头上**，不是算在公众号或管理员微信头上 |
| 关联 | 公众号与小程序之间的一根「绳子」 | 关联后才能在菜单、图文、客服消息里跳转 |

一句话：**公众号不能直接「变成」小程序，但可以用公众号的资质快速「生」出一个已关联的小程序。**

---

## 1. 用公众号快速注册并认证小程序

### 条件

- 境内主体：**已认证**的企业、媒体、其他组织类型公众号 / 服务号（**包括个体工商户**）。
- 境外主体：已认证服务号。
- **个人主体公众号没有这个入口**（个人只能走 mp.weixin.qq.com 常规注册）。
- 政府类型暂不支持复用资质快速注册。

### 入口

```
公众号后台 → 广告与服务 → 小程序管理 → 关联小程序 → 添加 → 快速注册并认证小程序
```

### 流程

1. 同意协议，管理员微信扫码验证。
2. 勾选要复用的资质：主体资质（默认）、运营者信息、微信认证资质（默认）。
3. 填写**全新邮箱**：必须未绑定任何个人微信、公众号、服务号、小程序、微信开放平台。
4. 邮件激活账号。
5. 绑定管理员（若第 2 步勾选了复用运营者信息，以最终绑定为准）。

### 好处

- 不用重新提交营业执照等主体材料；
- 不用对公打款 / 小额打款验证；
- **不用再付 300 元认证费**，复用公众号认证资质，认证到期时间与公众号一致（后续年审需小程序独立申请）；
- 生成的小程序与常规注册的小程序能力完全相同，有独立邮箱与密码。

### 限制

- 企业 / 媒体 / 其他组织公众号：**每月最多 5 个**（创建成功才占额度）。
- 个体工商户公众号：**每月最多 1 个**。
- 公众号若存在「待完成注册」的小程序，不能发起新的快速注册。
- 复用资质创建的小程序**默认与该公众号关联**，且不占「每月新增关联 13 次」的额度；但**不默认出现在公众号资料页**，需要手动开启展示，也不下发模板消息。
- 自 2023-12-25 起，通过**第三方平台代注册**接口新注册的账号默认为未认证状态；公众号后台自助快速注册仍可复用认证资质，具体以后台勾选页为准。

## 2. 到底能有几个小程序？（资质怎么算）

### 注册上限（按主体）

| 主体类型 | 上限 |
|---|---|
| 同一身份证（个人主体） | 5 个 |
| 同一企业 / 政府 / 媒体 / 其他组织资料 | 50 个 |
| 同一个体工商户 | 5 个 |
| 同一个邮箱 | 1 个 |
| 同一手机号码绑定 | 5 个 |
| 同一身份证 / 微信号绑定 | 5 个 |

要点：**主体注册次数不占公众号次数限制**；个人主体的身份证与管理员微信号绑定额度独立计算，不与组织类型重合。

### 备案上限（上架前必须备案）

| 主体 | 备案小程序上限 |
|---|---|
| 个人 | 5 个 |
| 个体工商户 | 5 个 |
| 企业 / 政府 / 媒体 / 其他组织 | 暂无上限（资料显示 50 个量级） |

> 2024 年起小程序上架前必须完成 ICP 备案，入口在小程序后台「设置 → 基本设置 → 备案」。备案数量上限与注册上限是两套口径，别混淆。

### 查询自己名下有多少

- 微信关注公众号「**公众平台安全助手**」（mphelper）→ 底部菜单「绑定查询」→ 查身份证 / 手机 / 微信号 / 企业绑定的小程序。
- 登录任一该主体的小程序 → 设置 → 基本信息 → 主体信息 → 详情 → 主体绑定账号 → 查询。

### 所以「我有多个小程序」是什么意思

你现有的多个小程序，只要**是同一个营业执照 / 同一身份证注册的**，就共用上面那个额度；它们彼此独立运营，但都可以被同一个公众号关联。换句话说：**决定你能再开几个的是主体剩余额度，不是公众号，也不是你已经开了几个公众号。**

## 3. 关联规则

| 项目 | 规则 |
|---|---|
| 谁能关联 | 所有公众号都可以关联小程序 |
| 一个公众号可关联 | 10 个**同主体**小程序 + 3 个**不同主体**小程序（部分文档写 10 + 10，以后台实时提示为准） |
| 一个小程序可关联 | 最多 500 个公众号 |
| 新增关联频率 | 公众号每月 13 次 |
| 快速注册产生的关联 | 默认关联，不占每月 13 次额度 |
| 未发布的小程序 | 可关联，但**不能**展示在资料页 / 图文 / 菜单（路径显示空白） |

关联流程：公众号后台 → 小程序管理 → 添加 → 关联小程序 → 管理员扫码 → 输入对方 AppID → 小程序管理员在微信里确认。

---

## 4. 挂到公众号里的 4 个位置

1. **自定义菜单**：内容与互动 → 自定义菜单 → 菜单内容选「跳转小程序」→ 选已关联的小程序 → 填小程序路径 + **备用网页**（必填，旧版微信不支持小程序时会打开备用网页；已认证公众号可设外链）。
2. **图文消息卡片**：新建图文 → 工具栏「小程序」→ 选小程序 → 填页面路径与卡片文字。
3. **自动回复 / 客服消息**：推送小程序卡片。
4. **公众号资料页「相关小程序」**：在小程序管理页开启展示；快速注册创建的不默认出现，需手动打开。

菜单路径要与 `app.json` 的 `pages` 一致，例如 `pages/index/index`。页面路径改动后，菜单和图文里的旧路径要同步更新。

## 5. 上线前的完整清单

- [ ] 用公众号快速注册小程序，拿到 AppID
- [ ] `miniprogram/project.config.json` 填入自己的 AppID
- [ ] `miniprogram/config.js` 填入你的网站域名与分享码
- [ ] 完成 **ICP 备案**
- [ ] 设置小程序名称、头像、简介、**服务类目**
- [ ] 微信开发者工具上传代码 → 小程序后台提交审核 → 发布
- [ ] 公众号后台确认已关联，配置自定义菜单 / 图文卡片
- [ ] 真机测试：从公众号菜单点进去，走完定制 → 复制链接 → 电脑打开 → 下载桌宠包

### 关于 web-view

`web-view` 组件只对**企业主体小程序**开放，且需要在后台配置业务域名、把校验文件放到网站根目录。本项目刻意不使用 web-view：
- 手机端生成链接，用户复制到**电脑浏览器**打开；
- 个人主体小程序也能用；
- 不需要服务器域名白名单，不需要云开发，零成本。

若以后升级成企业主体并想「小程序里直接打开定制网页」，再到小程序后台配置业务域名，把 `config.js` 的链接换成 web-view 页面即可。
